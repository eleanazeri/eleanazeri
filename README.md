## 🎓 Diploma Thesis

**Resource Congestion Control of Edge Compute Nodes Using Small Language Models and Episodic Memory Techniques**  
*Python · Docker · MQTT · ChromaDB · Oracle Cloud · Ollama · OpenRouter · Prometheus*

Building a fog-computing orchestrator that uses a locally-deployed 1.5B Small Language Model (Qwen2.5 via Ollama) to relieve overloaded edge nodes in real time — throttling, degrading, shedding, or relocating containerized processes across a 3-node cluster on an Oracle Cloud VM fleet. An episodic memory module (ChromaDB) retrieves past decision outcomes for in-context learning without fine-tuning, closed by a counterfactual reward engine. Evaluated on 19 containerized workloads monitored via Prometheus and controlled over MQTT, benchmarked against a remote 7B model to isolate model size as a variable.
